# Domain Docs

This project uses a **single-context** domain layout.

## Locations

- Terms and concepts: `GLOSSARY.md` at the repo root.
- Architecture Decision Records: `docs/adr/NNNN-title.md`.

## Consumer Rules

- Before implementing features with domain entities (e.g. Tenant, Claims, IPage, NodeID), consult `GLOSSARY.md` for definitions.
- When introducing a new architectural pattern, record an ADR in `docs/adr/`.
