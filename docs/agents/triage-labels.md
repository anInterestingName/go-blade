# Triage Label Vocabulary

This project uses the canonical five triage roles:

| Role | Label string | Purpose |
| :--- | :--- | :--- |
| Needs triage | `needs-triage` | Inbound, unreviewed issue |
| Needs info | `needs-info` | Blocked on human clarification |
| Ready for agent | `ready-for-agent` | Scoped and ready for autonomous agent implementation |
| Ready for human | `ready-for-human` | Requires human decision, architectural sign-off, or manual action |
| Won't fix | `wontfix` | Out of scope or rejected |
